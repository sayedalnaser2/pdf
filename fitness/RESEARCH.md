# Rest times by sport

Evidence levels: **R** research-based · **M** competition rules / match data · **C** coaching consensus · **X** extrapolated from a related sport.
Most sports have no direct rest-interval studies; levels C and X are practical starting points, not proven prescriptions.

## General

### Gym / no specific sport — evidence R (Research-based)
- Heavy-lift rest follows the goal default

## Endurance

### Running (5K–marathon) — evidence C (Coaching consensus)
- Heavy-lift rest on lifting days: 110 s
- 3–5 min VO₂max repeats: 2–4 min easy jog (≈1:1 work:rest, 3 min typical)
- 30/30 intervals: 30 s easy jog between reps
- Tempo / cruise intervals: 60–90 s jog
- Strides: 60–90 s walk-back (full recovery, form first)

### Trail / Ultra running — evidence X (Extrapolated from a related sport)
- Heavy-lift rest on lifting days: 110 s
- Hill repeats: walk/jog down as recovery (≈ equal to the climb time)
- Long runs: no fixed rest — walk steep sections, eat/drink every 30–45 min
- Descent drills: 60–90 s easy between reps to keep quads fresh

### Cycling (road, MTB, indoor) — evidence C (Coaching consensus)
- Heavy-lift rest on lifting days: 110 s
- VO₂max intervals (3–8 min): recovery ≈ equal to work (1:1)
- Threshold intervals: rest about half the work time (15 min on → 7–8 min off)
- Sweet spot: short recovery (≈5 min after 15–20 min blocks) to keep the stimulus going
- Rule of thumb: if power drops >5% below target, lengthen the rest

### Triathlon — evidence X (Extrapolated from a related sport)
- Heavy-lift rest on lifting days: 105 s
- Swim sets: 20–45 s between repeats
- Bike VO₂max intervals: 1:1; threshold: ½ work time
- Run intervals: 3-min repeats with 2–3 min jog
- Brick sessions: transition immediately — no rest

## Water

### Swimming — evidence C (Coaching consensus)
- Heavy-lift rest on lifting days: 100 s
- Aerobic sets: 20–30 s rest on short repeats, 30–60 s on 200s
- Threshold 100s: 20–40 s rest
- Sprints (10–50 m): full recovery, work:rest ≈ 1:6 or more
- Rest = same time as the swim (1:1) trains lactate tolerance; much longer shifts the set to aerobic

### Rowing / Kayak / Canoe — evidence X (Extrapolated from a related sport)
- Heavy-lift rest on lifting days: 120 s
- 500 m intervals: 1:30–2 min easy paddling (≈1:1)
- Long steady pieces: no rest
- Power strokes: 60–90 s between 10-stroke sets
- Heavy deadlift/row lifts need full 2–3 min recovery

### Surfing / Paddleboarding — evidence X (Extrapolated from a related sport)
- Heavy-lift rest on lifting days: 100 s
- Paddle sprints: 1:1 to 1:2 work:rest
- Pop-up sets: 30–45 s between sets
- Balance drills: 30–45 s

## Strength & Power

### CrossFit / HIIT classes — evidence C (Coaching consensus)
- Heavy-lift rest on lifting days: 105 s
- Heavy lifts: 2–3 min between sets
- Metabolic workouts: 1:1 to 2:1 work:rest
- AMRAP/EMOM: rest is built into the format
- Skill work: rest until technique is crisp (60–90 s)

### Powerlifting — evidence R (Research-based)
- Heavy-lift rest on lifting days: 210 s (upper-body ×0.75)
- Squat & deadlift: 3–5 min between heavy sets (3–5 min beat 1 min for absolute strength)
- Bench press & presses: 2–3 min is enough
- Accessories: 90–120 s
- Speed sets: 90–120 s — don’t let bar speed drop

### Olympic weightlifting — evidence R (Research-based)
- Heavy-lift rest on lifting days: 180 s
- Maximal snatch/clean & jerk: 3 min kept power and technique better than 2 min (elite study)
- Competition minimum between attempts: 2 min
- Technique/lighter sets: 90 s–2 min
- Front squats / pulls: 2–3 min

### Bodybuilding / Physique — evidence R (Research-based)
- Heavy-lift rest on lifting days: 105 s
- Rest longer than 60 s gives a small hypertrophy benefit; no meaningful extra benefit beyond ~90 s (2024 meta-analysis)
- Heavy compounds: 90–120 s
- Isolation: 45–60 s
- Supersets: rest only after the pair

### Calisthenics / Gymnastics — evidence C (Coaching consensus)
- Heavy-lift rest on lifting days: 150 s
- Static skills (planche, front lever, handstand): 2–3 min between holds
- Handstand push-ups / tuck planche: 120–150 s
- Strength sets (pull-ups, dips): 2 min
- Leave a few seconds in reserve — stop before form breaks

### Strongman / Highland games — evidence C (Coaching consensus)
- Heavy-lift rest on lifting days: 200 s
- Heavy short-distance yoke/carries: ~5 min between runs in heavy weeks
- Higher-volume weeks: ~2 min
- Sled work: ~2 min
- Accessories: 60–90 s

### Sprinting / Jumping / Throwing — evidence R (Research-based)
- Heavy-lift rest on lifting days: 180 s
- Sprints: full recovery (1:10+ ratio; 2–3 min between 30 m+ sprints)
- Plyometrics: 2–3 min between sets, 5–10 s between depth-jump reps
- Throws: 60–120 s
- Technique drills: walk back

## Team

### Football / Soccer — evidence R (Research-based)
- Heavy-lift rest on lifting days: 130 s
- Speed (20–30 m): 90–120 s walk-back — 60 s rest gave lower mean power than 90 or 120 s
- Short 15 m sprints: ≈1:10 work:rest gives full recovery; longer sprints need more
- Repeated-sprint conditioning: 1:1 to 1:3 once speed work is done
- Agility ladder / shuttles: 45–60 s

### Basketball — evidence R (Research-based)
- Heavy-lift rest on lifting days: 130 s
- Sprints: 60–90 s between 20–30 m runs
- Vertical jumps: full recovery, 90–120 s between sets of 4
- Defensive slides / suicides: 1:2 to 1:3 work:rest
- Ball-handling circuits: 30 s

## Racket

### Tennis / Badminton / Padel — evidence M (Rules & match data)
- Heavy-lift rest on lifting days: 100 s
- On-court drills: 1:2 to 1:5 work:rest (1:3 common for hard drills)
- Match reference: 20 s between points, 90 s changeovers, 120 s between sets
- Badminton: match ≈ 7 s work / 15 s rest; cutting rest from 15 s to 10 s lowered speed and stroke velocity
- Court sprints: 30–45 s

### Table tennis / Squash — evidence X (Extrapolated from a related sport)
- Heavy-lift rest on lifting days: 100 s
- Footwork shuffles: 1:2 work:rest
- Squash/table-tennis rallies: match-like 10–20 s pauses
- Reaction drills: 30–45 s

## Combat

### Boxing / Kickboxing / Muay Thai — evidence M (Rules & match data)
- Heavy-lift rest on lifting days: 120 s
- Pro boxing: 3-min rounds, 1-min rest (3:1) — mirror this on the bag
- Heavy bag / shadow rounds: 60 s between rounds
- Jump rope rounds: 60 s
- Heavy lifts: 2–3 min

### MMA / Wrestling / Judo / BJJ — evidence M (Rules & match data)
- Heavy-lift rest on lifting days: 120 s
- MMA: 5-min rounds, 1-min rest (5:1) — use 1 min between drilling rounds
- Judo bouts: work:rest ≈ 2.3:1 in repeated fights (n=6 study); judo rest between matches ≥ 2× match time
- BJJ competition: roughly 1 s hard : 5.6 s lower intensity (secondary source)
- Sprawl/shoot ladders: 1:1

### Karate / Taekwondo — evidence R (Research-based)
- Heavy-lift rest on lifting days: 110 s
- Kicking combos: 1 min between 2-min rounds
- Taekwondo study: 30 s work / 10 s rest beat 20/10 for VO₂peak (small adolescent study)
- Hip mobility: 20–30 s

### Fencing — evidence X (Extrapolated from a related sport)
- Heavy-lift rest on lifting days: 120 s
- Lunge drills: 1:3 work:rest (short, explosive)
- Footwork patterns: 45–60 s
- Reaction starts: 30–45 s
